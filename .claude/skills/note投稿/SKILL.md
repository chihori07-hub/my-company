## 書き方（9/16・9/27の型）

### 構成
1. **冒頭**：内心の声「 」を2つ前後 → 短い状況説明。問いかけから始めない
   - 内心の声は、素材があればちほさんの素材の言葉から取る。なければ生の言葉バンクから
   - **素材にない劇的な場面・小説のような描写を作らない**（例：「言い返せなくなった夫が黙りこむ。その瞬間、胸がすっとした。そのあとに残るのは、ひとりきりの静けさ」はNG）
2. **反転**：「でも実は、〜こと自体が、〜を苦しくしているわけではありません。苦しくなるのは、**〜**ときです。」
3. **見出し（###）3〜5個**で展開
   - 通説を静かに崩す
   - 心の仕組みを日常の言葉で（「一見ばらばら。でも奥にあるものは似ている」の形が効く）
   - **責任解除を必ず入れる**：「〜と、自分を責める必要はありません」。ターゲットは「言いすぎる私」「心が狭いのかな」と自分を責める人
   - 怒り・苛立ちの奥にある本音を、ラベルでなく言葉のまま置く（寂しかった／一人で抱えたくなかった）
   - 「〜することは、我慢することではない」で誤解を先に解く
4. **太字の一文**で気づきを結晶化（1記事に2〜4か所まで）
5. **締め＝感情のギフトで渡して終える**（2026-10-01〜）
   - 最後の数行は、読者に思考を求めない。読み終えた状態そのものを肯定する「許可・労い・後押し」の言葉で終える
   - 例：「もし今日、また〜してしまっても、大丈夫です」「〜と気づけたら、それだけで今日は十分」「ここまで、ひとりで頑張ってきたのだから」
   - **NG**：「いかがでしたか？」「参考になれば嬉しいです」、自分への問いかけや「〜してみてください」で終える形。どれも読者に感想・判定・考えること（宿題）を求める向きになり、読後の負担になる
   - 理由：読者は「役に立つ情報」だけでなく「どんな気持ちで日常に戻れるか」まで含めて記事を体験している。受け取った（楽になった・背中を押された）と感じたときに、スキやフォローが自然に起きる
   - 本文の途中で「本当は、何を伝えたかったんだろう？」と自分に聞く練習を紹介するのはよい。最後の一行を問いにしない
6. **区切り線（---）のあとにCTA**（スタイルガイド⑤の型。ガイドブック名・LINE。**署名は入れない**）
7. **ハッシュタグ**：`#夫婦関係 #パートナーシップ #自分軸 #自己受容 #心の仕組み #わたし基準 #自分を大切にする #40代女性 #50代女性` を基本に、テーマに応じて差し替え

### 文体
- 1〜2文で改行、空行を多めに（スマホで読む前提）
- 箇条書きは「・」
- 長さは2,500〜3,300字（9/16・9/27の実績。スタイルガイドの1,000〜1,800字より長めが今の勝ち型）
- 「エネルギー」は使ってよい（9/16・9/27で使用）。「エゴ」「マウント」「投影」などは日常の言葉に言い換える
- 比喩は1記事1つまで
- **同じ内容を2回書かない**。素材を活かしながら、1つの気づき・1つの言い回しは記事内で1回にする（冒頭・本文・実践・締めで同じことを言い直しがち）

### ちほさんから素材（メモ・構成案）をもらった場合
- 素材の構成と言葉をできるだけ活かす。ちほさんの言葉を勝手に別物にしない
- そのうえで、ターゲットと運用ルールに合わない箇所だけ直し、**何をなぜ変えたか**を提示時に表で示す

## 生成後にチェックしてから提示する

**ターゲット・軸（最優先）**
- [ ] 年齢や家庭の形（子どもの有無・世代など）で読者を絞りすぎていないか。メインは40代後半だが縛らない。悩みの質で「私のことだ」と思えるか
- [ ] 「言える層」と「飲み込む層」の両方に届くか（黙って我慢する妻としてだけ描いていないか）
- [ ] 責任感・言える強さ・正しさを欠点扱いしていないか。「言えているのは正しさ、願いはまだ言葉になっていない」の構造で描けているか
- [ ] 着地が「夫婦がうまくいく」ではなく「私が私をどう扱えるか／私の人生」になっているか
- [ ] 夫・相手の変化を成果の主語にしていないか（「夫が変わった」「関係がよくなる」「笑い合える関係が育つ」で終えていない）
- [ ] これまでの学びや努力を否定していないか。揺り戻し（頭では分かっても戻る）を失敗扱いしていないか
- [ ] 離婚を勧めたり、引き止めたりしていないか
- [ ] 「1人でも幸せになる」を使うなら、同じ記事に「1人でも幸せになれるから、一緒に幸せをつくれる」の意味の一文があるか

**表現**
- [ ] 冒頭が問いかけになっていない
- [ ] 締めが問い・宿題・「いかがでしたか」「参考になれば」になっていない。許可・労い・後押しで渡して終えている
- [ ] 「我慢していませんか」などのラベルで決めつけていない
- [ ] 評価語（ダメ・良くない・すべき）、専門用語、キラキラ、魔法のような、救う、煽りを使っていない
- [ ] 中庸：「素晴らしい」「一瞬で」「ピタッと」など極端な表現を穏やかにしている
- [ ] 「まとめ」を書いていない。結論後に言い換えていない
- [ ] **重複チェック**：同じ気づき・同じ言い回し（例：「胸がすっと」「そのままで大丈夫」「エネルギーの消耗」）が2回以上出ていないか。見出しごとに「この段落で初めて言うことは何か」を確かめる
- [ ] 素材にない劇的な場面描写を作っていないか
- [ ] 署名（東山知帆里（Coa-Terasu／コア・テラス））を入れていない
- [ ] CTAは区切り線のあと。本文の中で売っていない。「今すぐ」「限定」がない

## 提示・修正・保存（違和感の学習ループ）

1. タイトル案3つ（推奨1つ）＋本文全文＋ハッシュタグを提示する。素材から変えた点があれば表で示す
2. 末尾に「**違和感があった箇所だけ教えてください**」と添える（ちほさんに文章を直させない。書き直しはこちらの仕事）
3. 指摘があったら書き直し、確定後に `note-style-guide.md` の **違和感学習ログ** へ「直された箇所→違和感の種類→今後のルール」を1行追記する
4. 公開・反応の報告があったら、`note/過去記事/` に原稿を保存し、`README.md` の一覧と★を更新する

**下書きの保存先：**

```
.company/marketing/note/YYYY-MM-DD_テーマ一言.md
```

保存したらコミットしてpushする（別セッションからも見えるように）。
