# note記事作成

noteの記事（テーマ提案・下書き・書き直し）を作成する。

---

## ★ 最初に必ず行うこと（スキップ禁止）

以下の順番で読み込む。読み込みが完了したら、確認メッセージを出してから次に進む。

**Step 1：スタイルと学習ログを読む**
1. `.company/marketing/note-style-guide.md`（冒頭の「2026-10 更新」がv1より優先。末尾の**違和感学習ログを必ず全部読む**）
2. `.company/marketing/CLAUDE.md`（ブランドトーン・らしくない表現・NGスタンス）

**Step 2：最近の記事を読む（テーマの重複確認と、今の書き方の確認）**
3. Googleドライブの月別noteファイルの**直近2か月分**を、Drive MCPの `read_file_content`（`includeComments: true`）で全文読む
   - ファイル名は「2026/10月分note」「2026/8,9月分note」の形式。新しい月のファイルは `title contains '月分note'` で検索する
   - 2026-10-20時点のID: 「2026/10月分note」`1gdYIh9nDn9UpOSsA3yjOAU5axUDYs3PU3j1gh9uN1Zg`／「2026/8,9月分note」`1VY5zas8xg4sFoS72q0SCrdHvanA25JW-m7_jEr_0VYw`
   - 「反応が良かった」と書かれた記事は、今の勝ちパターンとして特に参考にする
4. `.company/marketing/note/過去記事/README.md` の一覧（2025/12〜2026/3の33本）と、★の記事を1〜2本

**Step 3：テーマに応じて読む**
5. 体験談・自己開示を書くとき → ストーリーバンク（正はGoogleドキュメント版。`.company/marketing/ストーリーバンク_東山知帆里_マスター.md` 冒頭のリンク先を読む）。**新しい語りを発明しない**
6. 読者の言葉が必要なとき → `.company/marketing/threads-style-guide.md` の「お客様の生の言葉バンク」
7. 動画・LINE特典など、ほかの資料が素材のとき → その資料を全部読む

**Step 4：読み込み確認を出力する**
以下の形式で必ず出力してから作業を開始する：

```
✅ note読み込み完了
- スタイルガイド（2026-10更新）と違和感学習ログ：◯件を確認
- 直近の記事：◯本を確認（日付とタイトルを列挙）
- 既に書いたテーマとの重なり：なし／あり（どの記事と重なるか）
```

この確認が出力できない場合は、ファイルが読み込めていない。その場合はパスやIDを確認してから再度読み込む。

## モードの判定

- **テーマ提案を頼まれた** → モード①
- **テーマが決まっていて下書きを頼まれた** → モード②

---

## モード①：テーマ提案

1. 直近の記事と過去記事一覧を見て、**まだ書いていない切り口**だけを提案する。似たテーマを書いている場合は、どの記事とどう違うかを必ず添える
2. 各案に、タイトル案（スタイルガイドのタイトルの型に沿う）と、記事の中心になる一言を付ける
3. おすすめを1つ選び、理由を添える

---

## モード②：下書き

1. スタイルガイドの「2026-10 更新」の基準（長さ・構成・小見出し・結び・LINE誘導）で書く
2. 場面描写や内心の声は、生の言葉バンクや最近の記事にある言葉の温度に合わせる。例文を発明しすぎない
3. NGチェックをしてから提示する

### NGチェック

- [ ] 直近2か月の記事とテーマが重なっていない
- [ ] タイトルに「あなたへ」を入れていない
- [ ] 小見出しが呼びかけ（「〜な方へ」）ではなく、中身を言い切る形になっている
- [ ] LINE誘導を見出しにしていない（区切り線のあとの定型文にする）
- [ ] 長さがテーマに合っている（2,500〜4,000字が中心。短めの回は1,000〜2,000字でもよい。提示時に字数を伝える）
- [ ] 1〜2文ごとに改行し、詰まって見えない
- [ ] 冒頭1行目が問いかけになっていない
- [ ] 「夫が悪い」という構図、評価語（ダメ・良くない・すべき）、専門用語を使っていない
- [ ] 「〜してください」という指示で終えていない
- [ ] 比喩は1記事1つまで

### 提示・修正・保存（違和感の学習ループ）

1. 下書きは**Googleドキュメント**で渡す（ちほさんがそのまま直せるように）。基本は月別noteファイルの該当日付の見出しの下に書き込む。別ファイルにする場合は、ちほさんに確認してから作る。リポジトリのmdファイルだけで渡さない
2. 末尾に「**違和感があったところだけ教えてください**」と添える
3. 指摘をもらったら書き直し、確定後に `note-style-guide.md` の違和感学習ログへ「直された箇所→違和感の種類→今後のルール」を1行追記する
4. 公開日が決まったら、秘書（`.company/secretary/todos/`）にリマインダーを入れる
