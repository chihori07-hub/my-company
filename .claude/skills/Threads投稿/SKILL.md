# Threads投稿作成

毎日のThreads投稿を作成する。

---

## ★ 最初に必ず行うこと（スキップ禁止）

以下の順番でファイルを読み込む。読み込みが完了したら、確認メッセージを出してから次に進む。

**Step 0：最上位ルールを読む**
- `.company/marketing/threads-プロジェクト指示書.md`（**Threads発信の最上位ルール**。目的・ターゲットの「表と裏」・2段構成・着地・避けること・13項目チェック。スタイルガイドと食い違う時は、必ずこちらを優先する）
- 常識A→新常識Bは `.company/marketing/ストーリーボード_人生再設定プログラム.md`

**Step 1：4点セットを読む**
1. `.company/marketing/threads-style-guide.md`（トーン・文体・生の言葉バンク・実績投稿の分析。構成ルールは指示書が優先）
2. `.company/marketing/threads-違和感パターン集.md`（**過去にちほさんが感じた違和感。同じものを二度と出さない**）
3. `.company/marketing/threads-ネタバンク.md`（投稿の種と6月実績の学び。ゼロから発想しない）
4. `.company/marketing/flow/Threads分析シート_2026後半.md` の直近2週間分（最新の当たり外れ。冒頭のスナップショット注記に従い、最新数値が必要ならDriveの原本を参照）

**Step 2：読み込み確認を出力する**
以下の形式で必ず出力してから作業を開始する：

```
✅ プロジェクト指示書読み込み完了（最上位ルール）
- ターゲットの「表と裏」／スレッド①最大6行・②本文・③は500字超の時のみ／着地は一つ／13項目チェックを確認
✅ スタイルガイド読み込み完了
- テーマ：A（逆説）/ B（原因）/ C（習慣）/ D（手放し）/ E（投資・行動教育）を確認
- E型3パターン：自己選択・投資誘導型 / 先延ばしコスト警告型 / 自己投資の正当化型 を確認
- 模範例①②③を確認
- 感情の動線8ステップを確認
- お客様の生の言葉バンク（3層構造・勝ちパターン4つ）を確認
```

この確認が出力できない場合は、ファイルが読み込めていない。その場合はファイルパスを確認してから再度読み込む。

## モードの判定

`$ARGUMENTS` を確認する。

- **引数なし** または **「週間テーマ」** → 週間テーマ企画モード
- **テーマが渡された** → 投稿下書きモード

---

## モード①：週間テーマ企画

1週間分（7日）のThreadsテーマを提案する。

### 手順

1. スタイルガイドのテーマ別パフォーマンス表を参照する
2. 以下のルールでテーマを組む
   - Aテーマ（逆説・否定形）を週2〜3回を軸に使う
   - **Eテーマ（投資・行動教育型）を週1〜2本必須で入れる**
   - 同じテーマは3投稿以上空けてから繰り返す
   - A→B→E→D→A のようにバランスよく配置する
3. 7日分を以下の形式で提案する。スレッド①の全文と、スレッド②冒頭のカギカッコ（答え）を両方記載する

```
月：[テーマ種別]
スレッド①：
〔スレッド①全文〕
↓
スレッド②冒頭：「〔答え〕」

火：[テーマ種別]
…（同様）
```

4. 確認・修正をもらい、確定したら `marketing/content-plan/` に保存する

## モード②：投稿下書き

渡されたテーマで スレッド①②（500字を超える時のみ③）の下書きを作成する。

### 手順

1. 指示書の「5．投稿で起こす視点転換」から、この投稿の視点転換を**一つだけ**決める。スタイルガイドのテーマ種別（A/B/C/D/E）も確認する
2. スレッドを生成する。**場面描写・内心の声・柔らかい本音・望みは、例文を発明せず、スタイルガイドの「お客様の生の言葉バンク」から引いて文脈に合わせて整える**（言葉の温度＝小ささ・具体さ・ためらいを保つ）

#### スレッド①（フック・問題提起／最大6行程度）
- 冒頭数秒で「誰向けの話か」「夫婦関係の話か」が分かり、「これ、私のことだ」と止まれる入り方にする
- 特に有効：本人が長所だと思っている姿→夫婦での裏側／当たり前にしている行動→意外な盲点／「できるはずなのに、なぜかできない」矛盾／問題だと思っていること→実は見る場所が違う
- 問いかけから始めない（「〜していませんか？」「こんなことありませんか？」「〜ではありませんか？」は冒頭に置かない）
- 「実は、」は使わない
- ①だけで話を完結させない。答えを説明し切らず、続きを読みたくなる一行で止める（「その理由は次へ」など露骨な煽りはしない）
- 実績のある締め方（`しないのは、` `手放したのは、` などの動詞句）は、自然な情報ギャップになる時に使ってよい

#### スレッド②（本文・視点転換・着地）
- 流れ：本人の行動 → なぜそうなるか → 見落としていた視点 → **一つの視点転換** → **一つの着地**
- 実績のある技法（②冒頭のカギカッコの「答え」、場面描写、内心の声、2段階の原因解放、柔らかい本音、「夫婦仲がいい妻は〜」の対比）は、この流れの中で必要な時に使う。8ステップを毎回すべて入れない
- 同じ意味の繰り返しは削る。必要な共感・具体例・心理・原因と結果は残す
- 一行15〜25文字目安で意味の切れ目で改行。2〜4行のまとまりで空行
- 結論後に言い換えない。**その投稿で最も残したい一行で止める**。余韻のための抽象的・詩的な一文を足さない
- 着地は一つだけ（視点転換の気づき／救いの言葉／今日からできる小さな一つ／希望／ときどき「私はどうしたい？」の問い）。成功の主体は夫ではなく本人

#### スレッド③（500文字を超えた時のみ）
- ②が500文字を超える時に分ける
- CTAは必要な投稿のみ。LINE特典『「私ばっかり」が終わる 生き方の選び直しガイド』へ、「自分が何を望んでいるか分からない」「夫を責めても自分を責めても苦しい」「我慢する／離婚するの二択から抜けたい」「自分の人生を自分で選び直したい」の文脈から自然につなげる（ブリッジはスタイルガイドのパターンA/Bを参考にしてよい）

**E型の場合：** スタイルガイドの「E型：投資・行動教育型」セクションと「模範例③」を参照する。使用したPDFポスト案の番号と型名を提案に明記する。

### 生成後にチェックをしてから提示する

**指示書の確認項目（最優先）**
- [ ] 一投稿一テーマ・視点転換は一つか
- [ ] ①は冒頭6行以内か／①だけで完結していないか／①の最後で②を読みたくなるか
- [ ] 冒頭で「私のこと」と止まれるか／夫婦のことだと分かるか
- [ ] 黙って我慢する妻として描いていないか／責任感・自立心・決断力・気配りを欠点扱いしていないか
- [ ] 「自分を直す人」に寄せすぎていないか／これまでの努力や学びを否定していないか
- [ ] 最後は夫から自分へ視点が移っているか／着地は一つか／読者が気づく余白があるか
- [ ] 「相手は変えられないから自分が変わろう」で終えていないか／離婚を勧めたり引き止めたりしていないか
- [ ] 「一人でも幸せになる」を使うなら、同じ投稿内に「一人でも幸せになれるから、一緒に幸せをつくれる」の意味の一文があるか

**表現のNGチェック**
- [ ] 冒頭が問いかけになっていない
- [ ] 「〇〇な人は〜しがち」という外部分析になっていない
- [ ] 「夫が悪い」という構図になっていない
- [ ] 評価語（ダメ・良くない・すべき）を使っていない
- [ ] 専門用語をそのまま使っていない
- [ ] 絵文字・ハッシュタグを使っていない
- [ ] 「本気の方だけ」という選別をしていない
- [ ] CTAで「LINE」「ミニセッション」という言葉を使っていない
- [ ] 「〜してください」という指示でCTAを終えていない
- [ ] `とはいえ、` はひらがな表記になっている

### 提示・修正・保存（違和感の学習ループ）

1. 下書き（スレッド①②、必要なら③）を提示する。末尾に「**違和感があった行の番号だけ教えてください**」と添える（ちほさんに文章を直させない。書き直しはこちらの仕事）
2. 短い指摘をもらって書き直す。**指摘があったら、確定後に `threads-違和感パターン集.md` へ「直された箇所→違和感の種類→今後のルール」を1行追記する**
3. 実績データが入ったら、使った種を `threads-ネタバンク.md` の使用ログに記入する
4. 確定したら以下に保存する

**保存先：**

```
.company/marketing/campaigns/threads/YYYY-MM-DD_テーマ一言.md
```
