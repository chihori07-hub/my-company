# 2026-10-23 学び

- [発信物の作成] note 下書きを、`.company/marketing/note-style-guide.md` とストーリーバンクを読まずに書いてしまい、体験談の創作・CTA・評価語（ダメ）・煽り寄りの前置き・文字数超過が出た。→ ルート CLAUDE.md に「発信物を作る前に必ず読むもの」を明記。ストーリーライティングは選べる書き方のひとつで、スタイルガイドが優先。
- [発信物の作成・追記] main が古く、9〜10月のルール（人生再設定プログラム・noteの長さ2,000〜2,600字・CTA定型文・締めの3パターンなど）が別ブランチ（lucid-tesla / festive-rubin / beautiful-davinci / modest-bardeen）に分かれていた。作業ブランチに統合した。main への取り込みはちほさんに確認する。
- [トーン] 「煽り」と「厳しく伝える」は違う（ちほさん）。煽り＝期限・不安・選別で急がせる。厳しさ＝現実と本人の選択から目をそらさず言い切る。
